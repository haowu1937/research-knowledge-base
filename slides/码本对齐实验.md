Codebook Alignment 实验计划

一、实验目标

本实验的目标是对齐不同训练阶段得到的 codebook，使新 codebook 生成的 SID 尽可能与旧 codebook 生成的 SID 保持一致。

具体来说：

1. 使用 12 月\-2 月的 item 训练得到 codebook 1。

2. 使用 codebook 1 为 12 月、1 月和 2 月的 item 生成 SID。

3. 使用 12 月\-3 月的 item 训练得到 codebook 2。

4. 使用 codebook 2 为 12 月、1 月、2 月和 3 月的 item 生成 SID。

5. 对 codebook 2 生成的 SID 进行重标号，使其尽可能接近 codebook 1 生成的 SID。

其中，对于 12 月、1 月和 2 月中已经存在于旧 codebook 中的 item，应尽可能保留它们原来的 SID 分配结果。

二、数据准备

为了进行新旧 SID 的对齐，需要让所有 item 同时拥有旧 SID 和新 SID。

首先，使用 codebook 1 为 3 月的 item 也生成一套旧 SID。这样，12 月、1 月、2 月和 3 月中的每个 item 都会有两套 SID：

old\_sid\[item\] = 使用 codebook 1 得到的旧 SID 分配结果

new\_sid\[item\] = 使用 codebook 2 得到的新 SID 分配结果

对于每个量化层级 l，每个 item 都有：

old\_sid\[item\]\[l\] = 该 item 在位置 l 上的旧 SID token

new\_sid\[item\]\[l\] = 该 item 在位置 l 上的新 SID token

三、Step 1：构建共现矩阵

对于每一个量化层级 l，构建一个共现矩阵 W\_l。

该矩阵用于统计：有多少 item 从旧 code b 被映射到了新 code a。

具体计算方式如下：

对于每个 item：

a = new\_sid\[item\]\[l\]

b = old\_sid\[item\]\[l\]

W\_l\[a, b\] += 1

其中：

a 表示新 SID 在第 l 层的 token

b 表示旧 SID 在第 l 层的 token

W\_l\[a, b\] 表示有多少 item 的旧 token 是 b，而新 token 是 a

因此，W\_l 反映了新旧 code token 在第 l 个量化层级上的对应关系。

四、Step 2：使用 Hungarian Algorithm 进行最优对齐

五、构建 SID 对齐函数

根据 Hungarian Algorithm 的结果，可以构建每一层的对齐函数 phi\_l：

phi\_l = {}

for a, b in zip\(row*ind, col*ind\):

```auto
phi_l[a] = b
```

例如，可能得到如下映射关系：

phi\_l = {0: 1, 1: 3, 2: 0, 3: 2}

它表示：

新 token 0 被映射到旧 token 1

新 token 1 被映射到旧 token 3

新 token 2 被映射到旧 token 0

新 token 3 被映射到旧 token 2

因此，对于每个 item，在第 l 层上可以得到对齐后的 SID：

aligned*sid\[item\]\[l\] = phi*l\[new\_sid\[item\]\[l\]\]

六、衡量对齐效果

完成 SID 重标号之后，可以计算每个 SID 层级上的 matched ratio，用于衡量新旧 SID 的对齐程度。

计算方式如下：

total\_*matched = W\[row*ind, col\_ind\].sum\(\)

matched*ratio = total*matched / total\_items

其中：

total\_matched 表示在最优映射关系下成功匹配的 item 数量

total\_items 表示参与对齐计算的 item 总数

matched\_ratio 越高，说明新旧 SID 在该层级上的一致性越强

matched\_ratio 越低，说明该层级上的 SID 分配发生了较大变化

七、实验结果

Position 0，也就是第一层codebook：

matched\_ratio = 0.1823

matched item 数量 = 800,003

总 item 数量 = 4,387,800

Position 1：

matched\_ratio = 0.0133

matched item 数量 = 58,212

总 item 数量 = 4,387,800

Position 2：

matched\_ratio = 0.0061

matched item 数量 = 26,851

总 item 数量 = 4,387,800

八、初步结论

实验结果显示，即使经过 Hungarian \(HG\) 算法进行重标号对齐，新旧 codebook 之间的 SID 分配仍然存在明显差异。

在第一层 sid\_0 上，只有 18.23% 的 item 能够被映射回与旧 codebook 一致的 token。

在更深层的 sid*1 和 sid*2 上，对齐比例进一步下降，分别只有 1.33% 和 0.61%。

这说明，当使用 12 月、1 月、2 月和 3 月重新训练 codebook 2 后，codebook 的 token 空间发生了明显重组。即使通过后处理方式进行 token relabelling，也只能恢复很少一部分原始 SID 分配关系。

因此，仅依赖 Hungarian Algorithm 对新旧 codebook 进行 token\-level alignment，可能不足以保证 SID 的时间稳定性。
